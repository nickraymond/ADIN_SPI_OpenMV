📖 HIL closed-loop run — launch, review, stop

S8 bite E4. The Pi shows a still, tells each camera to infer, each camera reports done, and only then does the still advance — sync errors are impossible by construction (no settle windows, no discarded frames). You watch and steer from a live page.

Run status: checking… Open the review page →

1. Start the screen (one click)

On the workbench, start the Urchin HIL — Monterey playback card (s8-hil-urchin). It owns the playback server (:8091) and the board locks; the bench LCD lights up by itself. One demo at a time — if another card is LIVE, stop it from the page first and wait out the 35 s settle.

2. Launch the harness (ssh terminal)

The harness runs in a terminal you keep open — it prints the scored summary there, and Ctrl-C is part of the stop story. Review mode (the run holds at every still for your Next):

ssh pi@nereus000
cd ~/ADIN_SPI_OpenMV && python3 -u pi/hil/hil_harness.py --closed-loop --review \
  --board 'N6=/dev/serial/by-id/usb-MicroPython_Pyboard_Virtual_Comm_Port_in_FS_Mode_020023000450433547373200-if00' \
  --board 'AE3=/dev/serial/by-id/usb-OpenMV_OpenMV_Camera_0829c14000000000-if00' \
  --phases nano-tiled --min-gt-px 30 --out ~/hil_runs/$(date +%Y%m%d)_review

Variants: drop a --board line for a solo run · --phases nano-tiled,tiny-tiled for more phases · omit --review for a hands-off scored run · --framesize HD for the HD tiling. Boards are ALWAYS the by-id paths — ttyACM<n> is enumeration order and the names are backwards from the guess (the "Pyboard" is the N6).

3. Review at the page

Open nereus000:8092 (the badge above goes green when a run is up). Top panel: the source still with GT green and each board's detections in its own colour, mapped through that board's homography. Per-board panels: the camera's own view with its detections in camera pixels — the truthful "what is this camera reporting".

A board shown DEAD has dropped out of the barrier (its reason is printed next to it) — the remaining boards continue solo and the run stays valid. That is the designed failure containment, not a broken run.

4. Stop, and leave the bench clean

  1. Abort run on the page (or let the run finish). The terminal prints the score table; artifacts land under ~/hil_runs/<name>/ (rows.jsonl, calib + overlays, power log).
  2. In review mode the page stays up for reading — Ctrl-C in the ssh terminal ends it. Board ports are already released by then.
  3. Done with the bench? Stop s8-hil-urchin from the workbench page (never by killing its process).

5. If it complains

FAIL: no playback server at http://localhost:8091 — step 1 was skipped; start the playback recipe first.

Page shows nothing at :8092 / Address already in use — a previous harness is still holding the port:

pkill -INT -f 'hil_harnes[s]'

(SIGINT, not -9: the harness unwinds through its clean path — boards told to end, ports released, collected frames scored.)

FAIL: calibration marker not visible in quadrant … — a camera or the screen moved; re-aim per the hil-screen chapter, then rerun.
