📖 Urchin HIL screen — set up the playback display

S8 bite E. The Monterey footage plays fullscreen on a screen; both bench cameras watch it; the matrix harness steps the same 80 stills Nick labeled. This chapter is the physical + display setup. The playback itself is the Urchin HIL — Monterey playback recipe card (start/stop it from the workbench page, like any demo).

1. Start the playback demo

On the workbench page, start Urchin HIL — Monterey playback. The badge above turns green when it is live. Media lives in /home/pi/hil_monterey/ (two clips + the frozen 80-still set); the recipe holds both board locks so no other demo can grab a camera mid-run.

2. Put the page on the screen the cameras will watch

Option A — any laptop/tablet (works today): open http://nereus000:8091/ in a browser on the device facing the cameras, click the page once, press f for fullscreen. Full brightness, auto-sleep OFF, fixed position — the calibration (step 4) is only valid while nothing moves.

Option B — the Pi's own HDMI screen (one-time setup, Nick's sudo): nereus000 is currently headless — no X/Wayland, no browser installed. When the display is hooked up:

sudo apt install --no-install-recommends xserver-xorg xinit chromium-browser
startx /usr/bin/chromium-browser --kiosk --noerrdialogs http://localhost:8091/ -- -nocursor

UNTESTED until a display is attached — package names are Pi-OS-bookworm's; if chromium-browser is not found, the package is plain chromium. Flag what apt actually installed back into this chapter.

3. Keys and modes

ffullscreen
lloop mode — clip looping (the demo eyeball + fps runs)
[ / ]previous / next clip
s, ←/→step mode — the 80 canonical stills, one at a time
ccalibration pattern (4 corner markers + center cross)
bblack screen (idle / power-floor readings)

The harness drives the same things over HTTP (POST /api/set) — the keys exist so a human can hand-drive without it.

4. Aim the cameras (framing check)

Goal: each camera sees the WHOLE content area, roughly square-on. Press c — the white border + corner markers ARE the content area. To see what a camera sees: stop the HIL demo on the workbench page, start N6 detection stream (or the two-colour demo), aim, stop it, restart the HIL demo. One demo at a time is the workbench rule; expect the 35 s settle countdown between stop and start.

After ANY camera or screen nudge, the screen→camera calibration must be re-shot (the harness does this at run start — a nudge mid-matrix invalidates the run, not just the calibration).

5. What the harness does with this (context)

Scored runs use step mode: the harness holds each still, stamps board captures with the still index, decodes + scores against Nick's labels. loop mode feeds the end-to-end fps rows and the live demo. Calibration maps Nick's label boxes into each camera's pixels so a tilted screen never scores as missed urchins.
