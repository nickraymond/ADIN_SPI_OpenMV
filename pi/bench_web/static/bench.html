The limits above (streams ≤ 315 rpmsg msg/s, stills ≤ 68 chunks/frame) are the measured boundary of the HE flood wedge: past them the camera node can go permanently mute and the recovery is a bench reboot (~3 min). With this ON, the page sends force with each command and the server lets it through — every override is logged in the bench-web journal.
